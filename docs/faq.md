## 一、关于 IP数据云

### Q01 什么是 IP数据云？

IP数据云 由江苏舍恩伯格信息科技有限公司运营，提供 IP 地址数据服务，产品数据为平台自有数据。数据覆盖全量 IPv4 与 IPv6，全球覆盖率 99.98%，每日更新且日处理 1,374G+ 数据；在线接口 0.01s 返回结果，支持 1000 次/秒并发。

按查询目标组织的能力矩阵覆盖归属地、风险画像、真人识别、应用场景、代理识别与宿主信息六类产品，交付形态分为在线 HTTPS 接口与本地离线库。

### Q02 IP数据云 提供哪些数据能力？

六个产品的返回结构与主要字段如下。

- **IP归属地** 的结果放在 `data.location`，里面有 continent、country、country_code、province、city、district、street、longitude、latitude、area_code、isp、time_zone、elevation、weather_station、zip_code、city_code，外加记录历史街道位置的 `multi_street`。IPv6 少了 street 和 multi_street，其余一样。示例中 `180.124.68.28` 落在江苏徐州泉山区，经纬度 `117.169163, 34.214855`，运营商电信。
- **IP风险画像** 把结果放在 `data.risk`，字段有 proxy、risk_tag、risk_score、risk_level、mb_rate、real；risk_tag 每一条带 label、label_name、last_time。风险标签包括垃圾注册、短信轰炸、黄牛、薅羊毛、垃圾信息、网络爬虫、端口扫描、高危设备、匿名通信、tor、hosing 等。
- **IP真人识别** 的 `data` 里有 mb_rate 秒拨概率、real 真人概率、isp、asn。
- **IP应用场景** 的 `data.scenes` 里有 isp、usage_type、asn；usage_type 覆盖 20 余种应用场景类型，包括 ANY 任播、CDN 内容分发、IDC 数据中心、DYN 家庭宽带、MOB 移动网络、BOGON 保留 IP。
- **IP代理识别** 的 `data.proxy` 里有 is_proxy、proxy、proxy_time，代理类型取值 tor、vpn、proxy、relay、hosting。
- **IP宿主信息** 返回行业、商圈、运营商、所属机构，示例 IPv4 `223.104.56.11` 对应行业酒店宾馆、运营商移动、商圈兰州绿色市场、所属机构中国移动。

六个产品共用同一端点，Key 按所选产品分配，`data` 结构随产品变化。

### Q04 如何开通并获取 API Key？

KEY 仅通过环境变量读取，不写入代码、版本库、Issue 或截图。Linux / macOS 导出方式如下。

```bash
export IPDATACLOUD_KEY="<YOUR_KEY>"
```

代码通过 `os.environ["IPDATACLOUD_KEY"]` 读取，仓库中不出现密钥值。环境变量为唯一推荐的注入方式。

端点 `https://api.ipdatacloud.com/v2/query`，支持 HTTPS GET 与 POST，返回 UTF-8 编码 JSON。请求示例（示例 IP `140.224.61.98`）：

```
https://api.ipdatacloud.com/v2/query?ip=140.224.61.98&key=<YOUR_KEY>
```

## 二、IP 地址与数据口径

### Q09 什么是 IP 地址？

IP 地址是互联网设备的逻辑标识，用于网络寻址与路由，分为 IPv4 与 IPv6。以 `112.250.91.9` 为例，返回中国山东泰安，经纬度 `36.194968, 117.129063`。

### Q10 IPv4 和 IPv6 有什么区别？

IPv4 为 32 位地址（如 `8.8.8.8`），IPv6 为 128 位地址（如 `2001:db8::1`）。数据覆盖全量 IPv4 与 IPv6；IPv6 归属地字段与 IPv4 基本一致，缺少 `street` 与 `multi_street`。IPv6 查询前须确认套餐支持。

### Q11 什么是 IP 归属地？能精确到什么程度？

IP 归属地是根据 IP 段分配和路由信息推断出来的地理位置，通常到国家、省、市和运营商这一层。IP归属地 在 `data.location` 返回 district 区县、street 街道、经纬度、area_code 行政区码、time_zone 时区、zip_code 邮编、city_code 城市代码，以及记录历史街道位置的 multi_street，每条带经纬度、半径 radius 和邮编。街道级能力需对应套餐。归属地为注册与路由信息推断结果，不等于设备实时坐标；跨境与新分配 IP 段偏差相对明显。

### Q12 什么是运营商和 ASN？

- **运营商** 是持有 IP 段、向用户提供网络服务的实体，比如电信、联通、移动，或海外 ISP。归属地和真人识别的返回里都有 isp 字段。
- **ASN** 是互联网独立路由实体的编号。IP应用场景 产品在 `data.scenes` 返回 `asn` 与 `isp`，示例中 `AS4134` 对应「电信」，用于标识 IP 所属网络与机构。

### Q13 什么是数据中心 IP、住宅 IP、代理和 VPN？为什么识别它们很重要？

- **数据中心 IP** 来自 IDC 或云厂商，常见于服务器、爬虫、自动化流量，IP应用场景 里对应 usage_type 的 IDC。
- **住宅 IP** 指家庭宽带分配给终端用户的地址，对应 usage_type 的 DYN 家庭宽带。
- **代理 / VPN** 为隐藏真实出口的中转地址，IP代理识别 把代理类型分成 tor、vpn、proxy、relay（如 Apple Private Relay）、hosting 五类，返回里还有 is_proxy 和最近一次代理发生时间 proxy_time。

风控、反欺诈、反外挂与反刷量场景需识别 IP 背后的用户真实性及机房、代理属性。IP风险画像 提供 risk_score、risk_level、mb_rate 秒拨概率与 real 真人概率，标签包含 tor、relay、hosing（机房或云服务商 IP）、网络爬虫、端口扫描。同一账号短时间从大量数据中心或代理 IP 接入，通常对应批量注册、打金工作室或异常登录，建议结合多维度字段联合判断。

### Q14 为什么同一个 IP 在不同平台查到的归属地可能不同？

各平台数据源、更新节奏与推断算法不同，边缘 IP 段、新分配段与跨境 IP 更易出现差异。归属地为推断值，跨平台差异属正常现象；海外 IP 的 `district` 与 `zip_code` 可能为空。建议结合风险评分、ASN 与网络类型联合判断。

### Q15 IP 查询的准确率与覆盖如何？

数据全球覆盖率 99.98%。主流 IP 段归属地较稳定，新分配段、移动网络、代理与 VPN 判定难度较高；建议结合威胁情报、ASN 与应用场景类型联合判断。定价页按城市、区县、街道三级精度分档，街道级与风险标签等字段按所选档位开放，不构成逐次查询的准确率保证。

`data` 中的空字符串是对应精度字段的套餐占位值，接口 `code` 仍为 0，属正常响应，不代表接口返回错误。区县、街道等细分字段按套餐覆盖范围提供，海外 IP 的部分编码字段也可能为空。调用成功与否以 `code` 判定，解析时对可选字段做兜底，避免单字段为空导致整条记录解析失败；如需完整字段与更高定位精度，可在 [IP数据云 官网](https://www.ipdatacloud.com/?utm-source=github&utm-keyword=?5741) 选择对应套餐升级。
