# IP 风险画像接口

按 IP 地址返回风险等级、风险评分与风险标签，用于登录、注册、营销活动等环节的实时风险判断。

## 一、接口说明

IP风险画像数据查询服务接口，返回 IP 的风险评分、风险等级、风险标签与代理识别结果。

## 二、接口方式

| 项目 | 规格 |
| --- | --- |
| 接口地址 | `https://api.ipdatacloud.com/v2/query` |
| 请求方式 | HTTPS GET / POST |
| 输出格式 | JSON |
| 字符集 | UTF-8 |

## 三、请求参数

| 字段名称 | 字段类型 | 是否必填 | 字段描述 | 备注 |
| --- | --- | --- | --- | --- |
| `ip` | String | 是 | IP 地址 | 支持 IPv4 |
| `key` | String | 是 | 产品密钥 | 根据所选产品分配，权限校验用 |

请求示例：

```
https://api.ipdatacloud.com/v2/query?ip=需要查询的ip&key=您申请的key
```

## 四、输出说明

| 字段名称 | 字段类型 | 字段描述 | 备注 |
| --- | --- | --- | --- |
| `code` | String | 状态码 | 参考状态码一节 |
| `msg` | String | 状态信息 | 请求成功时内容为 `success` |
| `data` | JsonObject | 输出信息 | 字段见 4.1 |

### 4.1 data 输出参数

| 字段名称 | 字段类型 | 字段描述 | 备注 |
| --- | --- | --- | --- |
| `proxy` | String | 是否代理 | 识别当前 IP 是否是代理，不是代理为空 |
| `risk_tag` | JsonObject | 风险标签 | 采集 IP 在使用中疑似发生风险行为，见 4.1.1 |
| `risk_score` | String | 风险评分 | 根据风险证据、风险标签、代理类型、发生时间及风险类型综合评分，可根据行业风控定制打分 |
| `risk_level` | String | 风险等级 | 根据风险评分进行等级划分，可根据行业要求定制评级 |
| `mb_rate` | String | 秒拨概率 | 评估 IP 地址产生的网络访问是否具有秒速拨号等异常特征，提供 0% 至 100% 的数值，值越高越有可能存在秒速拨号行为 |
| `real` | String | 真人概率 | 判别 IP 流量是否由真实人类产生，0% 至 99% 进行真人概率打分，接近 0% 意味着更趋近机器行为 |

### 4.1.1 risk_tag 输出参数

| 字段名称 | 字段类型 | 字段描述 | 备注 |
| --- | --- | --- | --- |
| `label` | String | 风险标签 | 参考 label 说明 |
| `label_name` | String | 风险标签名称 | 参考 label 说明 |
| `last_time` | String | 最近一次发生时间 | 格式 `yyyy-MM-dd HH:mm:ss` |

### 4.1.2 label 说明

| 返回参数 | 描述 |
| --- | --- |
| 垃圾注册 | 使用机器、脚本、虚假号码注册等符合风险注册特征的行为 |
| 短信轰炸 | 申请短信验证码次数、频次过高 |
| 黄牛 | 使用机器、脚本、相似地址重复参与下单的行为 |
| 薅羊毛 | 在营销实践中作弊、批量、重复领取优惠的行为 |
| 垃圾信息 | 该 IP 对应的账号频繁发布垃圾信息（涉政、色情、广告等文本或图片） |
| 网络异常设备 | 该 IP 曾被网络信息异常的设备持有使用过 |
| 篡改设备 | 该 IP 曾被篡改设备（设备参数被篡改、改机工具等）持有使用过 |
| 虚假设备 | 该 IP 曾被虚假设备（虚假设备、虚拟浏览器等）持有使用过 |
| 高危设备 | 该 IP 曾被高危设备（群控、检测绕过等）持有使用过 |
| 疑似虚假号码 | 该 IP 曾被疑似虚假号码持有使用过 |
| 疑似高危状态号码 | 该 IP 曾被疑似高危状态号码持有使用过 |
| 高风险手机号 | 该 IP 曾被高风险手机号持有使用过 |
| 网络爬虫 | 该 IP 因为大量进行网页爬取和信息收集而被标记 |
| 端口扫描 | 该 IP 因为频繁进行端口扫描、漏洞扫描而被标记 |
| 匿名通信 | 该 IP 因为长期运行开放式匿名代理服务而被标记 |
| hosing | 该 IP 属于机房 / 云服务商使用的 IP |
| tor | 通过多个网络节点进行多次加密，使整个传输过程难以追踪或识别数据来源和目的地 |
| relay | 指示专用中继服务是否存在于此 IP 上（Apple Private Relay 等） |

## 五、状态码

| code | msg | 备注 |
| --- | --- | --- |
| 200 | success | 请求调用成功 |
| 500 | 失败信息 | 请求失败原因（过期、次数不足、IP 类型错误等） |

## 六、返回值示例

```json
{
  "code": 200,
  "data": {
    "risk": {
      "mb_rate": "0.00%",
      "proxy": "是",
      "real": "51%",
      "risk_level": "中风险",
      "risk_score": 90,
      "risk_tag": [
        {
          "label": "highRiskDevice",
          "label_name": "高危设备",
          "last_time": "2024-05-10 12:17:26"
        }
      ]
    }
  },
  "msg": "success"
}
```

## 七、接入说明

- 风险评分与风险等级支持按行业风控定制，定制口径通过商务渠道确认。
- `risk_tag` 可能返回多条，也可能为空数组；解析时按数组遍历，不假定固定条数。
- `proxy` 为空表示当前 IP 未被识别为代理，不等于已确认为非代理环境。
- 风险结果用于辅助判断，阈值与处置动作由接入方按业务定义。
