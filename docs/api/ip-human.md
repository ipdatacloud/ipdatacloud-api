# IP 真人识别接口

按 IP 地址给出真人概率与秒拨概率，用于区分真实用户流量与机器生成的虚假流量。

## 一、接口说明

IP真人识别数据查询服务接口，返回 IP 的真人概率、秒拨概率、互联网提供商与 ASN 号。

## 二、接口方式

| 项目 | 规格 |
| --- | --- |
| 接口地址 | `https://api.ipdatacloud.com/v2/query` |
| 请求方式 | HTTPS GET / POST |
| 输出格式 | JSON |
| 字符集 | UTF-8 |

## 三、请求参数

| 字段名称 | 字段类型 | 是否必填 | 字段描述 | 备注 |
| --- | --- | --- | --- | --- |
| `ip` | String | 是 | IP 地址 | 同时支持 IPv4 和 IPv6 |
| `key` | String | 是 | 产品密钥 | 根据所选产品分配，权限校验用 |

请求示例：

```
https://api.ipdatacloud.com/v2/query?ip=需要查询的ip&key=您申请的key
```

## 四、输出说明

| 字段名称 | 字段类型 | 字段描述 | 备注 |
| --- | --- | --- | --- |
| `code` | String | 状态码 | 参考状态码一节 |
| `msg` | String | 状态信息 | 请求成功时内容为 `success` |
| `data` | JsonObject | 输出信息 | 请求失败时内容为空，字段见 4.1 |

### 4.1 data 输出参数

| 字段名称 | 字段类型 | 字段描述 |
| --- | --- | --- |
| `mb_rate` | String | 秒拨概率。评估 IP 地址产生的网络访问是否具有秒速拨号等异常特征，提供 0% 至 100% 的数值，值越高越有可能存在秒速拨号行为 |
| `real` | String | 真人概率。判别 IP 流量是否由真实人类产生，0% 至 99% 进行真人概率打分，接近 0% 意味着更趋近机器行为 |
| `isp` | String | 互联网提供商 |
| `asn` | String | ASN 号 |

## 五、状态码

| code | msg | 备注 |
| --- | --- | --- |
| 200 | success | 请求调用成功 |
| 500 | 失败信息 | 请求失败原因（过期、次数不足、IP 类型错误等） |

## 六、返回值示例

```json
{
  "code": 200,
  "data": {
    "asn": "AS4134",
    "isp": "电信",
    "mb_rate": "0.00%",
    "real": "52%"
  },
  "msg": "success"
}
```

## 七、接入说明

- `real` 与 `mb_rate` 均为百分比字符串，解析时去掉 `%` 再转数值。
- 两个概率是判断依据而非结论，处置阈值按业务场景设定，例如登录与注册可设不同阈值。
- 真人概率接近 0% 表示更趋近机器行为，不表示该 IP 一定由程序使用。
