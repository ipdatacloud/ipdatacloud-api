# IP 代理识别接口

按 IP 地址判断是否存在代理行为，并给出代理类型与最近一次代理发生时间，用于识别恶意访问、数据泄露与网络攻击。

## 一、接口说明

IP代理识别数据查询的服务接口，返回是否代理、代理类型与最近代理发生时间。

## 二、接口方式

| 项目 | 规格 |
| --- | --- |
| 接口地址 | `https://api.ipdatacloud.com/v2/query` |
| 请求方式 | HTTPS GET / POST |
| 输出格式 | JSON |
| 字符集 | UTF-8 |

## 三、请求参数

| 字段名称 | 字段类型 | 是否必填 | 字段描述 | 备注 |
| --- | --- | --- | --- | --- |
| `ip` | String | 是 | IP 地址 | 同时支持 IPv4 和 IPv6 |
| `key` | String | 是 | 产品密钥 | 根据所选产品分配，权限校验用 |

请求示例：

```
https://api.ipdatacloud.com/v2/query?ip=需要查询的ip&key=您申请的key
```

## 四、输出说明

| 字段名称 | 字段类型 | 字段描述 | 备注 |
| --- | --- | --- | --- |
| `code` | String | 状态码 | 参考状态码一节 |
| `msg` | String | 状态信息 | 请求成功时内容为 `success` |
| `data` | JsonObject | 输出信息 | 字段见 4.1 |

### 4.1 data 输出参数

| 字段名称 | 字段类型 | 字段描述 | 备注 |
| --- | --- | --- | --- |
| `is_proxy` | String | 是否代理 | 当无代理时为空 |
| `proxy` | String | 代理类型 | 详情见 4.1.1 |
| `proxy_time` | String | 最近代理发生时间 | |

### 4.1.1 proxy 输出参数

| 返回参数 | 描述 |
| --- | --- |
| tor | 代理节点快速动态变化的加密三重代理 |
| vpn | 通过使用专用线路或在现有网络上使用隧道协议创建一个虚拟的点对点连接而形成 |
| proxy | 网络代理，是一种特殊的网络服务，允许一个网络终端通过这个服务与另一个网络终端进行非直接的连接 |
| relay | 指示专用中继服务是否存在于此 IP 上（Apple Private Relay 等） |
| hosting | 指数据中心类型 |

## 五、状态码

| code | msg | 备注 |
| --- | --- | --- |
| 200 | success | 请求调用成功 |
| 500 | 失败信息 | 请求失败原因（过期、次数不足、IP 类型错误等） |

## 六、返回值示例

```json
{
  "code": 200,
  "data": {
    "proxy": {
      "is_proxy": "是",
      "proxy": "vpn",
      "proxy_time": "2024-05-13 09:05:58"
    }
  },
  "msg": "success"
}
```

## 七、接入说明

- `is_proxy` 为空表示未识别到代理行为，`proxy` 与 `proxy_time` 同时为空。
- `proxy` 返回英文枚举值，业务侧按 4.1.1 映射为中文类型。
- `proxy_time` 为最近一次识别到代理行为的时间，空值表示无历史记录。
- 数据中心类型（`hosting`）不属于匿名代理，风控策略中通常与 vpn、tor 分开处置。
